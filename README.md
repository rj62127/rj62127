### 🔐 SentryFuse — Secret Leak Detection Platform

A security platform for detecting credentials and secrets before they reach production.

**Architecture**

`GitHub App → Webhook Service → Kafka → Detection Engine → Notification Pipeline`

**Stack**

`Go` `Kafka` `GitHub Apps` `CI/CD` `Slack` `PagerDuty`

Designed around asynchronous event processing and scalable security scanning.

### 🗄️ Database Governance Service

A FastAPI microservice that proactively detects **auto-increment / integer ID exhaustion** across database fleets before applications start failing.

**Stack**

`FastAPI` `SQLAlchemy 2.0` `PostgreSQL` `MySQL` `Alembic` `Docker`

Key engineering work:

* Pluggable database scanner architecture
* PostgreSQL sequence & system catalog inspection
* MySQL `information_schema` analysis
* Cross-database health aggregation
* Encrypted database credentials
* Scan lifecycle tracking
* Layered Router → Service → Repository architecture
